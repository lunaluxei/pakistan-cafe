# Pakistan Cafe Website

A modern, responsive cafe website designed with an elegant layout and a warm visual style.

## Features
- Responsive homepage and navigation
- Interactive food menu with category filters
- Food photography for menu highlights
- Animated 3D coffee cup created with Three.js
- Cafe location linked to Google Maps

## Technologies Used
- HTML
- CSS
- JavaScript
- Three.js

## Project Purpose
This project was created to practise frontend web development, improve design skills, and explore interactive 3D elements for a cafe website.

## Deployment
Hosted using cloudeflare Pages
